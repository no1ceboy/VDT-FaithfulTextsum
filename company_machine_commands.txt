VDT-FaithfulTextsum company run

From the repo root, use the IT-approved environment. Do not pip-install or
download models from Hugging Face. Merge the current code ZIP over the source;
preserve `models/`.

Extract MiniCheck into the existing cache (the ZIP has files at its root):

  python -m zipfile -e VDT-FaithfulTextsum-MiniCheck-Flan-T5-Large.zip models/hf-cache

10-record evaluation smoke test (`input`, `human_sum`, `llm_sum`):

  python -m src.evaluate.run_eval --data /data/vdt/summaries.jsonl --summary_cols human_sum llm_sum --metrics factcc minicheck alignscore rouge --offline --nltk_data_dir models/nltk_data --batch_size 2 --limit 10 --output results/smoke.jsonl

After it succeeds, rerun without `--limit 10`; change output to
`results/baseline.jsonl`.

GRPO pilot (after baseline evaluation; requires IT-provisioned TRL/PEFT and a
local 3B instruct checkpoint):

  python scripts/prepare_grpo_data.py --input /data/vdt/summaries.jsonl --output_dir /data/vdt/grpo_splits --source_col input --reference_col human_sum --validation_fraction 0.1 --test_fraction 0.1 --seed 42
  python scripts/train_grpo.py --model models/Llama-3.2-3B-Instruct --train_jsonl /data/vdt/grpo_splits/train.jsonl --output_dir models/runs/grpo_minicheck_001 --faithfulness_metrics minicheck --hf_cache_dir models/hf-cache --num_generations 4 --reference_weight 0.25 --seed 42

The input file's reference-field name must match `--reference_col` (for
example, the included sample uses `abstract_sum`; company data may use
`human_sum`). For multiple same-schema JSONL files, list all paths after
`--input`; they are combined before one grouped split, with per-file IDs
namespaced. Only `train.jsonl` is used for training; validation/test stay held
out. The pilot reward is exploratory for Vietnamese. See `GRPO_EXPERIMENT.md`.
